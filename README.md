# Сүз — татарча өйрән

**Сүздән җөмләгә** — татар телен уйнап өйрәнү өчен кушымта: 12 юнит, 300 сүз, 96 җөмлә.

Приложение для изучения татарского языка в формате коротких ежедневных уроков: 12 юнитов, 300 слов с эмодзи и латинской транслитерацией, 96 фраз, повторение по системе интервалов, банк ошибок, словарь, достижения и недельная дуэль по ссылке.

## Что уже есть

- 60 уроков: по 4 урока и контрольная в каждом юните.
- Упражнения: выбор перевода, эмодзи → слово, сборка предложения, пропущенное слово, набор текста, соединение пар.
- Повторно ошибочные слова добавляются в банк ошибок, возвращаются в конце текущего урока и подгружаются в следующие уроки.
- XP, стрик, сердца, кристаллы, ежедневная цель, задания дня, достижения и статистика.
- Интервальное повторение и словарь с поиском.
- Дуэль на неделю по ссылке/QR-коду без регистрации.
- Переключение кириллица/латиница (Zamanälif), светлая и тёмная темы.
- PWA: офлайн-режим, установка на Android и iPhone.
- Прогресс хранится локально в IndexedDB, аккаунт не нужен.

## Стек

React 19 + TypeScript + Vite 8, Zustand, `idb-keyval`, `vite-plugin-pwa`. Для Android-сборки предусмотрен Capacitor (см. `vite.config.ts`, режим `APP_BUILD=1`).

## Запуск

```bash
npm install
npm run dev
```

Проверка контента:

```bash
npm run content:check
```

Сборка:

```bash
npm run build
```

Экспорт контента для носителя (CSV + HTML):

```bash
npm run content:check
npm run content:export
```

## Публикация

PWA: **https://w1nday12.github.io/suz/**

Сборка из `dist` публикуется в ветку `gh-pages`. После изменений:

```bash
npm run build
npx gh-pages -d dist
```

### Установка на iPhone

Safari → «Поделиться» → «На экран "Домой"».

### Установка на Android

**Вариант 1 — PWA:** открыть ссылку в Chrome → «Установить приложение» (или меню → «Добавить на главный экран»).

**Вариант 2 — APK:** [suz-app-release.apk](https://github.com/W1nday12/suz/releases/download/v1.0.0/suz-app-release.apk) (~3.6 MB, подписан).

Если раньше была установлена debug-версия, её нужно сначала удалить — подписи не совпадают:

```bash
adb uninstall com.w1nday12.suz
adb install -r suz-app-release.apk
```

Пересобрать APK после изменений:

```bash
npm run build:app
npx cap sync android
cd android && ./gradlew assembleRelease
```

## Контент

Источник слов и фраз — `src/data/course.ts`. Спорные слова помечены уровнем `medium` и сопроводительным комментарием; список для проверки носителем выводит `npm run content:check`.

Аудио пока нет: архитектура готова к подключению нейросетевого TTS, но текущие упражнения текстовые.
